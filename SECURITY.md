# Security Policy

## Supported versions

Security fixes are prioritized for the latest tagged release and the current default branch. Before the first tagged release, report issues against the current default branch.

## Reporting a vulnerability

Please do not open a public issue for an unpatched vulnerability. Use GitHub's private vulnerability reporting for this repository from the **Security** tab. The repository owner should keep that feature enabled. If private reporting is unavailable, contact the maintainer through [github.com/nsamartsev](https://github.com/nsamartsev) and request a private reporting channel.

Include the affected version or commit, the impact, and steps to reproduce when possible. The maintainer will acknowledge the report and coordinate a fix and disclosure timeline with the reporter.
